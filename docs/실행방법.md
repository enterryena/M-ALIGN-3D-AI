# 실행 방법

세 가지 방법이 있습니다. 화면만 빨리 보려면 **방법 1**, 기록을 PC에 남기며 쓰려면 **방법 2 또는 3**을 쓰세요.

| 방법 | 준비물 | 기록 저장 | 걸리는 시간 |
|---|---|---|---|
| 1. 브라우저 데모 | 웹 브라우저 (Chrome, Edge) | 브라우저 안에만 | 바로 |
| 2. Python으로 실행 | Windows 10/11 + Python 3.10 이상 | PC에 영구 저장 | Python 설치 후 바로 |
| 3. EXE 만들어 실행 | 만드는 PC에 Python 3.10 이상 (처음 1회 인터넷) | PC에 영구 저장 | 빌드 수 분 |

두 판의 계산 엔진과 결과는 같습니다(기준 가정 · 시드 2026 · 1,000회에서 기존 격자 68회, 이력 추정 586회 성공).

---

## 방법 1. 브라우저 데모 (설치 없음)

1. 저장소에서 `browser_demo/MAS-kit_브라우저_데모_v3_4.html`을 내려받습니다. GitHub 파일 화면 오른쪽 위의 다운로드 버튼(Download raw file)을 누르면 됩니다.
2. 내려받은 파일을 더블클릭해 Chrome이나 Edge로 엽니다.
3. 오른쪽 **실행 설정**에서 시나리오와 위치 추정 방식을 고르고 **▶ 1회 작업 실행 (랜덤 오차)**을 누르면 기계 준비 → 메인 서버 지시 → 회차별 센싱(약 6회) → 메인 동작 순서로 3D 애니메이션이 재생됩니다. 메인 서버를 설정하지 않으면 내장 시뮬 서버가 지시합니다 ([`전송_프로토콜.md`](전송_프로토콜.md)).
4. **■ 성공률 계산**을 누르면 100~1,000회 성공률이 나옵니다.

- 기록은 그 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 사라지니 필요하면 **누적 전체 JSON 내보내기**로 따로 저장하세요.
- `app/MASKIT_Desktop.html`(정식판)을 직접 열면 화면은 보이지만 성공률 계산이 막혀 있습니다. 정식판은 방법 2·3으로 실행하세요.

---

## 방법 2. Python으로 실행 (정식판, EXE 없이)

**준비 (처음 1회)**
1. [python.org](https://www.python.org/downloads/windows/)에서 Python 3.11 또는 3.12 Windows 설치 파일을 받아 설치합니다.
   - 설치 첫 화면에서 **Add python.exe to PATH**를 체크하세요.
   - 기본 설치에 포함된 tkinter(관리 창)를 그대로 둡니다. 추가 패키지 설치는 필요 없습니다.
2. 저장소 전체를 내려받아(초록색 **Code → Download ZIP**) 압축을 **완전히** 풉니다. 압축 파일 안에서 바로 실행하지 마세요.

**실행**
1. `app` 폴더의 `RUN_WITH_PYTHON.cmd`를 더블클릭합니다.
2. 작은 **데이터 관리 창**이 뜨고, 잠시 뒤 기본 브라우저에 시뮬레이터가 열립니다.
3. 브라우저가 안 열리면 관리 창의 **주소 복사**를 누르고 Chrome·Edge 주소창에 붙여넣으세요(`http://127.0.0.1:숫자/` 형태).
4. 다 쓰면 **관리 창을 닫습니다.** 창을 닫으면 프로그램이 끝나고, 기록은 남습니다.

---

## 방법 3. EXE 만들어 실행 (정식판)

**만들기 (만드는 PC에서 1회)**
1. 방법 2의 준비를 마칩니다(Python 설치, 압축 완전 해제).
2. `app` 폴더의 `BUILD_EXE.cmd`를 더블클릭합니다. 창에 다음 4단계가 차례로 나옵니다.
   - `[1/4]` 빌드 전용 환경 만들기 (`.build_env` 폴더)
   - `[2/4]` PyInstaller 확인·설치 (처음 1회 인터넷 필요)
   - `[3/4]` 저장 기능 자동 시험 (PASS가 여러 줄 나와야 정상)
   - `[4/4]` EXE 만들기
3. `SUCCESS`가 나오면 `app\dist\MASKIT_Desktop.exe`가 생기고 그 폴더가 자동으로 열립니다.
4. `BUILD FAILED`가 나오면 바로 위 오류 문구를 확인하세요. 기존 저장 기록은 건드리지 않습니다.

**실행**
1. `MASKIT_Desktop.exe`를 더블클릭합니다. 이 EXE 하나만 다른 Windows PC로 복사해도 실행됩니다(Python 불필요).
2. 처음 실행하면 Windows가 **"Windows의 PC 보호"** 경고를 띄울 수 있습니다. 코드 서명이 없는 개인 제작 프로그램이라 그렇습니다. **추가 정보 → 실행**을 누르세요.
3. 이후 화면은 방법 2와 같습니다.

---

## 관리 창 버튼

| 버튼 | 하는 일 |
|---|---|
| 시뮬레이터 열기 | 브라우저에 시뮬레이터를 다시 엽니다 |
| 주소 복사 | 시뮬레이터 주소를 복사합니다 (브라우저가 자동으로 안 열릴 때) |
| 저장 폴더 열기 | 기록 파일(`cases.sqlite3`)과 백업 폴더를 엽니다 |
| 저장 기록 백업 | 지금 상태로 백업 파일을 새로 만듭니다 |
| 프로그램 + 모든 누적 기록 완전 제거 | 기록 전체와 실행 중인 EXE를 삭제합니다. 되돌릴 수 없습니다 |

관리 창에는 누적 성공·실패·전체 건수가 계속 표시됩니다.

## 기록이 저장되는 곳

- `%LOCALAPPDATA%\MASKIT\CaseBank\cases.sqlite3`
  예: `C:\Users\(윈도우 계정)\AppData\Local\MASKIT\CaseBank\cases.sqlite3`
- EXE를 다른 폴더나 드라이브로 옮겨도 같은 Windows 계정이면 같은 기록을 씁니다.
- 다른 PC나 다른 Windows 계정과는 자동으로 공유되지 않습니다. 옮기려면 시뮬레이터 화면의 **누적 전체 JSON 내보내기 → 이전 JSON 불러오기**를 쓰세요.
- 매일 1회와 정상 종료할 때 자동 백업이 `backups` 폴더에 생깁니다.
- 브라우저 데모(방법 1)의 기록은 이 파일과 공유되지 않습니다.

## 발표 수치를 그대로 재현하려면

1. **매 실행마다 새 무작위 시드** 체크를 끕니다.
2. 하드웨어 오차 가정: 기준 가정 / 위치 추정 방식: 기존 격자 추정기 / 초기 오차 반경: 30 mm
3. 시험 횟수 1,000회, 시험 시드 `2026` → **■ 성공률 계산**
4. 결과: 6.8% (성공 68 / 1,000). 위치 추정 방식을 이력 추정으로 바꾸면 58.6% (586 / 1,000)

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `RUN_WITH_PYTHON.cmd`가 바로 닫히거나 Python을 못 찾음 | Python을 다시 설치하며 **Add python.exe to PATH** 체크 |
| 브라우저가 안 열림 | 관리 창 **주소 복사** → Chrome·Edge 주소창에 붙여넣기 |
| 학교·회사 PC에서 화면이 안 뜸 | 보안 정책이 내 PC 안 주소(127.0.0.1) 접속을 막는 경우. 방법 1(브라우저 데모) 사용 |
| `BUILD_EXE.cmd`의 `[2/4]`에서 실패 | 인터넷 연결 확인 후 다시 실행 (PyInstaller 설치 단계) |
| `[3/4]`에서 WinError 32 | v3.5.3 이전 문제로, 이 v3.5.4에서 수정됨. 최신 압축을 새 폴더에 풀어 다시 실행 |
| 시작할 때 "MAS-kit 시작 오류" 창 | 창에 적힌 오류 기록 파일(`...\MASKIT\CaseBank\logs\startup_errors.log`) 확인. 기존 기록은 삭제되지 않음 |

## 지우기

- 프로그램 안에서: 관리 창의 **프로그램 + 모든 누적 기록 완전 제거** → 경고 확인 → `완전삭제` 입력
- 빌드 폴더에서: `app\REMOVE_MASKIT.cmd` 더블클릭 → `DELETE` 입력
- 두 방법 모두 `%LOCALAPPDATA%\MASKIT` 폴더와 `MASKIT_Desktop.exe`만 지우며, 되돌릴 수 없습니다. 자세한 내용은 `app/DELETE_GUIDE_KO.txt`를 보세요.
