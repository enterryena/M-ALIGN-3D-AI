MAS-kit v3.5.4 — 프로그램과 누적 기록 완전 제거 안내
=====================================================

1. EXE를 실행해서 제거하는 경우 (권장)
   - MAS-kit 데이터 관리 창 아래의 '프로그램 + 모든 누적 기록 완전 제거' 클릭
   - 경고 확인 → '완전삭제' 직접 입력
   - MAS-kit의 다른 창이 종료되면 제거 도구가 실행됨
   - 이 PC의 현재 Windows 사용자 계정 %LOCALAPPDATA%\MASKIT 폴더 전체와
     지금 실행한 MASKIT_Desktop.exe를 삭제
   - 사례 DB·-wal·-shm·일일 백업·종료 백업·삭제 전 백업·오류 로그 모두 포함
   - 삭제 직전 새 백업을 만들지 않음. 영구 삭제이며 취소/복원 불가.

2. EXE를 실행하기 어려운 경우 (개발용 ZIP 포함)
   - 실행 중인 MAS-kit 창을 전부 닫기
   - 압축을 푼 배포 폴더에서 REMOVE_MASKIT.cmd 실행
   - DELETE 입력 → 같은 사용자 데이터와 dist\MASKIT_Desktop.exe 삭제

3. 자동으로 제거하지 않는 것
   - 다운로드 폴더의 원본 ZIP, 배포된 다른 EXE 복사본, 프로젝트 소스/보고서
   - 예전 HTML 시뮬레이터가 웹 브라우저 IndexedDB에 저장한 기록
   - Chrome/Edge 방문 기록, 다운로드 기록, Windows Prefetch/이벤트/보안 로그,
     백신 기록 등 앱이 직접 관리하지 않는 운영체제 자료
   - 다른 Windows 사용자 계정의 MAS-kit 사례와 백업

4. 중요
   - 일반적으로 EXE 파일만 휴지통에서 지워서는 AppData의 사례 기록이 삭제되지 않습니다.
   - 완전 제거를 먼저 수행한 다음 다운로드 ZIP/소스 등을 직접 지우세요.
   - 관리자 권한이나 무차별 시스템 정리 도구는 필요하지 않습니다.
   - Windows 자체의 모든 흔적을 100% 지운다고 보증하지 않습니다.

5. 검증 정보
   - Linux 환경에서 기존 WinError32 백업 회귀 테스트, 저장/재시작, 경로 고정,
     실제 HTML-서버-SQLite 연결 및 100회 재현(6 성공, 94 실패) 통과.
   - Windows PowerShell 실행·PyInstaller EXE 생성 및 제거는 배포 전에
     별도의 Windows 테스트 계정에서 반드시 검증해야 합니다.
