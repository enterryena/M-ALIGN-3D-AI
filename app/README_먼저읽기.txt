MAS-kit v3.5.4  |  Windows 배포/영구 사례 누적
===============================================

[핵심: 저장 위치는 EXE 위치와 무관]
항상 현재 Windows 사용자 계정의 다음 경로에 저장합니다.
%LOCALAPPDATA%\MASKIT\CaseBank\cases.sqlite3
예: C:\Users\(윈도우 계정)\AppData\Local\MASKIT\CaseBank\cases.sqlite3
- EXE를 D:나 E:로 옮겨도, 업데이트된 EXE로 교체해도 같은 Windows 계정이면 저장 위치는 같습니다.
- 동일 PC라도 다른 Windows 계정은 서로 다른 저장소를 사용합니다.
- 다른 컴퓨터는 자동 동기화되지 않으므로 JSON 또는 SQLite 백업으로 이관해야 합니다.
- 앱은 저장 경로를 찾지 못하거나 DB가 손상되면 빈 저장소로 조용히 우회하지 않고 오류를 알려줍니다.
- 데이터는 프로그램 실행 파일의 폴더에 저장하지 않습니다.

[EXE 만들기: ZIP 압축 해제 후 더블클릭]
1. ZIP의 압축을 완전히 풉니다. ZIP 내부에서 바로 실행하지 마세요.
2. Windows 10/11 + Python 3.10 이상(권장 3.11/3.12)이 준비되어 있어야 합니다.
3. BUILD_EXE.cmd 더블클릭. 처음에는 PyInstaller 설치를 위해 인터넷이 필요할 수 있습니다.
4. 생성물: dist\MASKIT_Desktop.exe. 다른 Windows PC로 옮길 때는 이 EXE만으로 실행됩니다.
5. EXE를 더블클릭하면 작은 데이터 관리 창이 열리고 기본 브라우저에 시뮬레이터가 나타납니다.
   MASKIT_Desktop.html을 직접 열면 별도 저장소를 만들지 않도록 실행이 차단됩니다.
6. 사용자는 '시뮬레이터 열기', '주소 복사', '저장 폴더 열기', '저장 기록 백업' 버튼을 사용할 수 있습니다.
※ 아래의 배포 패키지는 EXE 자체가 아니라 Windows에서 EXE를 만드는 소스 및 빌더입니다.
※ 코드 서명되지 않은 개인 제작 EXE는 Windows SmartScreen의 게시자 확인 경고가 나올 수 있습니다.
   일반 사용자 배포 전 실제 Windows PC에서 빌드/실행 및 보안 검사, 가능하면 코드 서명이 필요합니다.

[성공/실패 누적 동작]
- 랜덤 오차 1회 실행 및 100/300/500/1000회 반복 시험에서 결과를 자동 저장합니다.
- 저장 성공이 확인되면 누적 성공/실패/총 건수가 갱신됩니다.
- 실패 건도 저장합니다. 같은 조건 + 같은 시드 + 시행번호는 중복 집계하지 않습니다.
- 카메라 없음. 센서 추정기는 Matrix5 5헤드 측정과 명령한 이동량만 사용합니다.
- 시뮬레이터 내부 정답은 판정/3D 표시 전용이며 제어기에는 입력되지 않습니다.
- '성공 사례 보관'은 자동 학습과 다릅니다. 성공 기록을 다음 제어기에 자동 입력하지 않습니다.
- 기준 하드웨어 시나리오 성공률이 70%를 넘도록 조작하지 않았습니다.

[기록 보존/복구]
- PC 데이터를 덮어쓰지 않고 SQLite에 지속적으로 추가합니다(WAL + FULL).
- 앱 시작 시 DB를 무결성 검사합니다. 기존 사례가 있으면 매일 1회 백업을 저장합니다(최근 14개).
- 정상 종료할 때도 최신 데이터를 백업합니다(최근 7개 종료 백업).
- '저장 기록 백업' 버튼으로 언제든 새 백업 파일 생성 가능.
- 누적 기록 삭제는 2회 확인 후에만 진행하며 삭제 직전에 자동 SQLite 백업합니다.
- 관리 창의 '저장 폴더 열기' 버튼에서 실제 파일과 backups 폴더를 볼 수 있습니다.
- '누적 전체 JSON 내보내기' / '이전 JSON 불러오기'로 PC 간 자료를 이관할 수 있습니다.
- 과거 v3.4 HTML의 IndexedDB 사례는 웹 브라우저 저장소이므로 EXE로 자동 이관되지 않습니다.
  과거 HTML에서 JSON 내보내기 -> 이 EXE에서 '이전 JSON 불러오기' 순서로 이관하세요.
- 실수로 SQLite 파일을 삭제하지 마세요. 특히 앱이 열려 있을 때 백업 파일을 직접 덮어쓰지 마세요.

[한계 및 발표 주의]
- 데스크톱 EXE는 브라우저 UI를 내 PC의 127.0.0.1 로컬 서버에 표시합니다. 외부 서버와 통신하지 않습니다.
- 각 시험의 결과는 Maxwell Matrix5 21개 응답과 가정된 편향/공극/기울기에 따른 가상 결과입니다.
- 정렬 ±5mm 실물 달성, 실물 체결 성공률, 상용 안정성을 보증하지 않습니다.
- 현장 사용 또는 실물 하드웨어 제어용이 아닙니다.

[롤백]
ROLLBACK\v3_3_History.html 및 v3_4_IndexDB.html은 개발 검증 기록용으로만 보관.
이 파일을 따로 실행하면 브라우저 저장소를 사용하므로 PC SQLite와 기록이 공유되지 않습니다.
코드 롤백해도 SQLite 파일은 별도 저장되어 삭제되지 않습니다.

[검증 범위]
- Python 구문/JavaScript 구문, SQLite 저장 후 재실행 유지, 중복 제거, 100회 재현/저장 확인.
- 이 환경은 Windows가 아니므로 실제 PyInstaller EXE의 Windows 실행 검증은 아직 불가능합니다.
- 실사용 배포 전 Windows 빌드 및 실행 테스트가 반드시 필요합니다.


[중요: 배포 후 완전 제거 — v3.5.3]
* 프로그램 관리창의 '프로그램 + 모든 누적 기록 완전 제거'를 누르고, 두 번 확인하면
  현재 Windows 사용자 계정의 %LOCALAPPDATA%\MASKIT 폴더(성공/실패 사례,
  cases.sqlite3 / -wal / -shm, backups, logs, 설정)를 모두 삭제하고,
  EXE가 MASKIT_Desktop.exe로 실행 중이면 해당 EXE 파일도 함께 삭제합니다.
* 개발/빌드용 ZIP에서 지울 때는 REMOVE_MASKIT.cmd를 더블클릭한 뒤 DELETE 입력.
  dist\MASKIT_Desktop.exe 및 동일 사용자 데이터 폴더만 제거합니다.
  Python/소스/다운로드 ZIP은 배포 파일이므로 사용자가 별도로 제거하세요.
* 삭제는 되돌릴 수 없습니다. 삭제 직전 자동 백업은 생성하지 않습니다.
* 프로그램을 다른 계정에서 사용했으면 각 계정마다 제거하세요.
* 이전 브라우저용 HTML의 IndexedDB, 브라우저 기록, Windows 자체 실행 기록,
  백신/시스템 로그, 다른 폴더로 복사된 EXE·ZIP은 임의로 건드리지 않습니다.
  따라서 모든 운영체제 흔적이 사라진다고 보장하지 않습니다.
* EXE 위치를 옮겨도 사례 저장 위치는 기존과 동일합니다. 저장 위치 변경 없음.
